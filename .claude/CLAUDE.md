## Architecture Overview

This is an FRC robot project for the 2026 Rebuilt season using WPILib 2026 and CTRE Phoenix 6.

### Key Patterns

**Singleton Subsystems**: All subsystems use the singleton pattern via `getInstance()`. Never instantiate subsystems directly.

**Superstructure State Machine**: `Superstructure.java` coordinates subsystem states through a central state machine with request methods (`requestHome()`, `requestIdle()`).

**Control Flow**:
- `Robot.java` - TimedRobot entry point, initializes subsystems and scheduler
- `ControlBoard.java` - Handles driver/operator controller bindings and input processing
- `AutonSubsystem.java` - Manages autonomous routines via Choreo's AutoFactory

### Swerve Drive

Uses CTRE's generated swerve (`TunerSwerveDrivetrain`) with:
- `TunerConstants.java` - Generated by Tuner X, contains module configurations and motor IDs
- `SwerveSubsystem.java` - Extends `TunerSwerveDrivetrain`, implements `Subsystem` interface
- `SwerveConstants.java` - PathPlanner config and auto constants

The swerve drivetrain is on a dedicated CAN bus named "Drivebus".

### Simulation (MapleSim)

Physics simulation uses MapleSim with Dyn4j physics engine in `org.ironmaple.simulation`:
- `SimulatedArena` - Central physics world managing all simulated objects
- `Arena2026Rebuilt` - Season-specific field with obstacles, hubs, outposts, and fuel game pieces
- `MapleSimSwerveDrivetrain` - Bridges CTRE swerve with MapleSim physics
- `IntakeSimulation` - Simulates game piece collection with contact detection

Simulation runs on a separate Notifier thread at 500Hz. Game pieces are visualized via NetworkTables for AdvantageScope's 3D field view.

### Vendor Dependencies

- **Phoenix 6** - CTRE motor controllers (TalonFX), CANcoders, Pigeon 2
- **PathPlanner** - Autonomous path planning
- **ChoreoLib** - Trajectory following
- **REVLib** - REV hardware support
- **Limelight (yall.json)** - Vision processing
- **MapleSim** - Physics simulation (partially integrated, see `subsystems/simulation/`)

### Utility Classes

- `TunableParameter` - Live-tunable values via SmartDashboard with callbacks
- `PS5Controller` - Custom PS5 controller wrapper in `frc.lib`
- `CTREConfig`/`CTREUtil` - CTRE configuration helpers

### Vision

`LimelightSubsystem` handles AprilTag localization with alliance-based tag filtering.
