# PathPlanner Paths and Autos

This directory contains path and autonomous files generated by [PathPlanner](https://github.com/mjansen4857/pathplanner), a motion profile generator and path planning tool for FRC robots.

## Purpose

PathPlanner is used for:
- Autonomous path planning with waypoints
- Dynamic pathfinding during autonomous and teleop
- Visualization of robot paths on the field

## How to Create Paths

1. Download and install PathPlanner from the [releases page](https://github.com/mjansen4857/pathplanner/releases)
2. Open PathPlanner and load this project
3. Configure robot settings (dimensions, max velocity, constraints)
4. Create paths (.path files) and autonomous routines (.auto files)
5. Files are automatically saved to this directory

## Directory Structure

PathPlanner typically creates subdirectories:
- `paths/` - Individual path segments (.path files)
- `autos/` - Complete autonomous routines (.auto files)

## How Paths Are Used

The `SwerveSubsystem` is configured with PathPlanner's `AutoBuilder`:

```java
AutoBuilder.configure(
    this::getPose,
    null,
    this::getChassisSpeeds,
    this::drive,
    controller,
    SwerveConstants.robotConfig,
    () -> false,
    this);
```

This enables:
- Following pre-planned paths during autonomous
- Dynamic pathfinding with LocalADStar algorithm
- Integration with the command-based framework

## Deployment

All files in this directory are automatically deployed to the RoboRIO at `/home/lvuser/deploy/pathplanner/` when you run `./gradlew deploy`.

## Notes

- PathPlanner paths can be run independently or combined in autonomous routines
- The PathPlanner GUI provides real-time visualization of your robot following paths
- This codebase uses PathPlannerLib version 2026.1.2 (see vendordeps/PathplannerLib-2026.1.2.json)
