# Choreo Trajectories

This directory contains trajectory files (.traj) generated by [Choreo](https://github.com/SleipnirGroup/Choreo), a trajectory optimization tool for FRC robots.

## Purpose

Choreo trajectories are used for autonomous routines. The `AutonSubsystem` loads these trajectories at runtime and follows them during the autonomous period.

## How to Create Trajectories

1. Download and install Choreo from the [releases page](https://github.com/SleipnirGroup/Choreo/releases)
2. Open Choreo and configure your robot parameters (wheelbase, max velocity, etc.)
3. Design your autonomous paths using the GUI
4. Export the trajectories to this directory as `.traj` files

## How Trajectories Are Used

The `AutonSubsystem.java` loads trajectories using ChoreoLib's `AutoFactory`:

```java
AutoTrajectory trajectory = routine.trajectory(name, index);
```

Trajectories are followed using the swerve drivetrain's `followPath()` method, which uses PID control to track the desired path.

## Deployment

All files in this directory are automatically deployed to the RoboRIO at `/home/lvuser/deploy/choreo/` when you run `./gradlew deploy`.

## File Naming

- Trajectory files should be named according to your autonomous routine names
- Use descriptive names like `FourPieceAuto.traj` or `CenterLineRush.traj`
- The name you use here must match the name you use in `AutonSubsystem.java`
